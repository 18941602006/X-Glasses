# 产品需求 / V3

状态：设计约束，不是已实现功能。硬件、模型和指标均需阶段验证。完整来源及设计见根方案 V3。

## 目标与范围

ESP32-S3 / 首选 XIAO ESP32-S3 Sense 采集，前期游戏本计算，最终骁龙 8 系列 Android 本地计算。手机具体型号尚未确定。通过 USB 数据线传 JPEG、ToF、IMU、按键及双向控制；首版 USB 供电，同一时刻一个主机。

| 需求 | 验收阶段 | 关键边界 |
| --- | --- | --- |
| 道路候选步行区分割 + 近距避障 | 3 | 车行道不默认可走，ToF 无效标未知 |
| LocateAnything 找物 + 拿取辅助 | 4 | 用户拿取，无机械臂；晚到结果、遮挡降级、用户确认 |
| 行人信号灯状态识别 | 5 | 不发通行许可，方向不明提示无法确认 |
| 地图步行导航 | 5/6 | 地图事件不等于已确认道路安全；定位由手机/外部适配器提供 |
| OCR 阅读 | 5 | 清晰度/阅读顺序，保留原文，不虚构识别结果 |
| AI 对话 | 5 | 按需联网，不参与实时风险决策 |

排除 SLAM、盲道/斑马线专项模型、对齐/自动过街流程及其接口、页面、命令。道路分割仍保留。

## 手部与交互

LocateAnything 二维定位 + 连续目标跟踪 + MediaPipe 手部 + ToF 多区测距；内外参/裁剪和时间标定后才融合。分区与框重叠不证明深度归属；手物共区或遮挡时停止数值前后引导。用户按键/语音确认拿取，不以握拳或二维重叠替代。

电脑新调试台（Phase 2B）提供 USB、帧龄、有效性、叠加、日志、标定/回放和命令确认。手机（Phase 6）五任务入口、TalkBack、大触控、取消/重复、USB 授权与后台处理，不共用桌面 UI 代码。

## 安全、隐私及待确认

风险/失效提示优先；所有提示带来源和有效期。USB 拔线且断电由主机告警，不宣称眼镜无电运行；单前向 ToF 不覆盖所有脚下落差。测试受控、有陪同、保留盲杖，不独立过街。

录制/上传需用户触发，默认不长期保存图像/语音。LocateAnything 源码与权重分开审核，许可用途未确认不得下载；手机本地失败需用户决策，不默认换模型或上云。具体硬件模块、引脚/供电、地图地区与服务、手机型号在对应阶段确认。
