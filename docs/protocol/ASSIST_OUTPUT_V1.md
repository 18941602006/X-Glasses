# ASSIST_OUTPUT_V1

Phase 5 的供应商无关辅助事件与输出仲裁合同。信号灯、地图、OCR、对话输入必须回显当前 session/correlation/provider 或 model，严格拒绝额外字段、过期事件和无界文本；uint64 session 在外部 JSON 中使用十进制字符串。

固定输出优先级：传感器失效 > 紧急风险 > 局部避障方向 > 信号灯观测 > 地图 > 找物 > 阅读 > 对话。同类只保留最新有效事件，支持按 correlation 取消并限频；换会话清空。仲裁层不读图像、不加载模型，输出层不得重新推理。

行人信号灯仅报告 red/green/unknown 与方向是否明确。即使识别为 green，也必须附带“不是过街许可”；地图、OCR 和对话不能产生安全通行结论，也不能压过实时近障或传感器失效提示。
