# Android 地图步行导航合同 v1

流程：目的地文字 → 最多五个地点候选 → 用户明确选择 → 新鲜且可用的手机位置 → pedestrian 路线 → 逐步地图提示。地图提示只描述外部路线，不证明眼前道路可走；ToF/道路感知的失效、停止和局部方向优先于地图。

位置使用 Android `elapsedRealtime`，不得用收到时间或墙钟冒充采样时间。默认门限为位置最多 10 秒、精度不差于 50 米、距离步骤目标 14 米推进、目的地 18 米视为“到达附近”、偏离路线 45 米连续三次才重算。它们是保守代码初值，不是实测参数，真机测试后须版本化调整。

状态只有 `IDLE/ROUTING/ACTIVE/PAUSED/REROUTE_REQUIRED/ARRIVED/FAILED`。低精度、过期位置、服务失败、空路线或非法响应不能保持旧指令；到达只播报“目的地附近”，仍需现场确认入口。应用不申请后台位置，离开前台即停止位置监听；恢复前台后只在权限仍有效时恢复。

地点搜索和路线服务必须通过 `NavigationProvider` 注入，生产配置仅 HTTPS，禁止在仓库硬编码密钥或依赖公共演示服务器。当前适配 Photon GeoJSON 与 Valhalla pedestrian JSON/polyline6；不同服务必须新增显式 adapter 和固定契约测试，不能只换 URL 猜测兼容。
