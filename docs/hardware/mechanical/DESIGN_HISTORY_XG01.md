# XG-01 导盲眼镜结构方案 / 概念定稿 01

日期：2026-10-24。授权：用户确认文字路线后要求在 Blender 建模。

## 设计决定

采用运动型双镜片镜框、中央可拆感知舱、左右电子镜腿、可换软鼻托与耳套。深灰主体、钛灰盖板、青蓝操作标识。USB 单线连接电脑，计算与音频输出位于主机。眼镜不设置电池，开放式耳机连接主机；上一轮文字方案中的眼镜音频仅保留为后续可能的结构变更，不作为现有器件。

中央感知舱安放 XIAO ESP32-S3 Sense 主板/相机叠层及单颗 VL53L5CX 转接板，共用刚性支架。相机和 ToF 平行朝前、水平邻近。双孔面板、独立 ToF 遮光通道和隔断作为光学设计占位；首版不封普通深色塑料窗。窗口透光率、视场遮挡、串扰与隔断位置须按到货器件及光学应用资料重新验证。

右镜腿预留 LSM6DSOX 转接板和 USB 线槽；左镜腿预留 DRV2605L 驱动、ERM 马达、主确认键与取消/重复键。数据线从右耳后引出。弯折余量、线径、USB 延长连接方式及铰链过线仅作空间示意，尚未完成电气或疲劳验证。

## 装配和拆解

21个集合对应21个装配组。每个零件含part_id/design_status属性；父级Empty控制爆炸位移。镜片、镜片压框、前框、感知舱外壳/前后盖、相机叠层、ToF、刚性支架、鼻托、左右镜腿、内盖、IMU、震动驱动/马达、按键、耳套、线缆与紧固件独立编辑。

时间轴1-35帧完整装配，35-110展开，110-150停留，150-225还原，225-240完整停留。24 fps时间轴总长10秒。爆炸动作是展示布局，不是工人严格拆卸顺序或物理装配路径仿真；开始检修前应先断电、解除线缆连接，再松螺钉、拆盖和模块。当前不含镜腿折叠运动验算。

核心装配关系：镜片入框并压框固定 → 鼻托 → 镜腿及铰链 → 感知支架/器件 → 走线/镜腿电子件 → 可拆前后盖/内盖 → 应力释放/耳套。螺钉和定位件为概念尺寸，不宣称螺纹、公差和刀具可达性已经验收。

## 文件与复现

本机交付目录：`artifacts/mechanical/xg01/`（按项目规则忽略，不上传生成产物）。

- `X-Glasses_XG01.blend`：原生可编辑文件，包含21组拆装关键帧、材质、灯光、相机和内嵌中文操作说明。

- `build_report.json` / `verification.json`：构建与重开检验记录。
- `assembly_preview.mp4`：生成成功时提供的低采样展示视频，原生动画以blend为准。

使用本机Blender4.5.2 LTS，从仓库根目录执行：

```powershell
& 'C:/Program Files/Blender Foundation/Blender 4.5/blender.exe' --background --factory-startup --python-exit-code 1 --python docs/hardware/mechanical/build_xg01.py -- --render
& 'C:/Program Files/Blender Foundation/Blender 4.5/blender.exe' --background artifacts/mechanical/xg01/X-Glasses_XG01.blend --python-exit-code 1 --python docs/hardware/mechanical/verify_xg01.py
```

交互：打开blend后空格播放，时间轴输入1/130/240查看装配/爆炸/还原；小键盘0切换相机，Outliner展开01-21集合选择零件。不要直接覆盖用户另外保存的修改版；复现脚本只用于本轮生成目录，已有定制成果应另存或用--output指定新目录。
