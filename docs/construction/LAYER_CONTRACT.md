# 分层与数据合同 / 设计级

当前 server/common 与 server/input 已实现协议/组帧/回放，以及 [CONTROL_V1](../protocol/CONTROL_V1.md) 的主机握手/心跳/对时/传感器/ACK 状态机和可选串口驱动。固件执行/实际传感器/对时误差/USB 未验证；后续层仍为目标责任合同，不能把结构字段当作实际能力。底层布局见 [USB_V1](../protocol/USB_V1.md)。

| 层 | 输入/输出 | 禁止 |
| --- | --- | --- |
| firmware | 相机/ToF/IMU/键 → USB 包；主机命令 → 驱动/ACK | 视觉推理、语义导航、通行决策 |
| server/input | USB 字节 → 校验/组帧/对时后的样本与失效事件 | 加载模型、直接播放提示 |
| server/common | 协议/帧/事件/时钟定义 | 依赖具体感知或硬件实现 |
| perception/navigation | 同步图像/ToF → 风险/方向候选 | 盲道/斑马线/SLAM、直接控制输出 |
| perception/locate | 文字查询/帧 → 定位/跟踪/手部融合事件 | 阻塞实时链路、旧深度指导拿取 |
| perception/assist | 拍照/地图/对话 → 结构化辅助事件 | 安全通行许可 |
| arbitration | 事件 → 带期限的唯一输出决策 | 读原始相机、加载模型 |
| output | 仲裁结果 → 音频/USB 震动命令 | 重新做感知和导航 |
| frontend | 状态订阅/用户请求 → 后端 request_id | 直控硬件或自行宣布执行成功 |
| tools | 公开数据合同 → 回放/校准/评测 | 导入模型私有实现 |

## 必备字段与生命周期

USB 消息：协议版本、session_id、类型、序号、设备采样时间、长度、完整性校验；JPEG 分片包含 frame_id、总长、偏移。校验和长度/缓冲上限、短读/短写、超时重同步、分片取消/过期策略都需测试。CDC 不混入裸文本日志。

标准帧/样本携带设备/session/frame 标识、原采样时间/主机映射时间、质量/有效性和标定版本。接收时间不能充当曝光时间；晚到结果要可靠追溯传播，否则废弃。ToF 必须保留分区状态/质量，禁止无效距离当空旷。

候选事件携带来源、采样关联、风险类别、有效截止时间、优先级、可信/未知原因；确认命令用 request_id、执行结果/超时、当前设备状态。断连清除过期指引；幂等/重试范围在协议冻结时定义。所有生产/消费队列有上限，不可靠历史帧不得无限排队。

## MCU 与拿取例外

仅 MCU 仍有电时允许本地有效近距阈值/数据失效提示，阈值/滞回/限频须实测；固件统一调度本地与主机输出并回报主机。USB 供电拔线导致掉电时由主机提示失联。

拿取目标/手/ToF 的空间与时间归属必须可信；共区、遮挡、失跟降级。有限时/有限区域的预期目标重复提示抑制不能屏蔽其他风险及失效。感知层永远不得绕过仲裁驱动扬声器/马达。
