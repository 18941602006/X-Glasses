# 分阶段施工计划

| Phase | 施工内容 | 放行条件 |
| --- | --- | --- |
| 0 | Git 安全基线/备份、施工文档、目录职责、venv、检查工具 | lint/基础工具测试/结构/忽略检查、文档一致、交付远端核验 |
| 1 | 开源底座/依赖/代码和权重许可审核、具体硬件接口、手机风险预审 | 版本/来源/许可证台账、兼容性结论和未解决项；使用权重前确认用途 |
| 2A | ESP-IDF 固件、USB 协议、输入、时间对齐及基础反馈 | 编译/协议异常测试；30 分钟链路与断连/供电实测 |
| 2B | 新电脑前端、状态确认、录制回放、标定入口 | 构建/交互测试、过期叠加和取消；模拟/实机明确标识 |
| 3 | 道路分割、ToF 风险融合与行进提示 | 漏报/误报/延迟、未知/光照/头动受控测试 |
| 4 | LocateAnything、跟踪、手部/ToF 融合、拿取确认 | 标定、晚到/遮挡/多物/错误深度归属及用户确认测试 |
| 5 | OCR、灯状态、地图和对话 | 错误/网络异常/提示抢占/取消测试，无安全过街承诺 |
| 6 | Android USB Host/本地模型/无障碍 UI | 真机后台/功耗/温升/时延、LocateAnything 迁移结论 |

按检查点推进，不把缺硬件的模拟测试等同实机放行。每次真实施工前创建新备份，不长期复用 Phase 0 备份。一般细节记录后续处理；身份/权限/授权用途/用户数据安全等硬门槛必须暂停询问。范围或硬件升级需记录决策，不偷偷替换指定识物模型。
