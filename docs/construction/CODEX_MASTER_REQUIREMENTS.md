# 施工主要求 / V3

本文件是根《X-Glasses施工规范V3.md》的索引摘要，不替代其全文。产品范围由方案 V3 及产品需求约束；冲突按根规范优先级处理。

- 身份：Trollhunter / d.o.n.0907@qq.com，经用户确认；origin 仅 git@github.com:18941602006/X-Glasses.git。
- 先计划和成功远端备份，后施工；显式暂存，不覆盖用户改动，不强推。
- Phase 0 只文档、层 README、空配置、最小依赖/检查；后续 Phase 1 审核、2A USB、2B 新前端、3 行进、4 拿取、5 辅助、6 Android。
- ESP-IDF/esp_tinyusb 原生 USB CDC，非 Wi-Fi 推流或 UART 桥视频；有限分片/队列/过期/确认。
- 无 SLAM、盲道和斑马线专项运行模块；保留道路分割和灯状态。
- 主机感知不得直连输出；LocateAnything 独立 worker。MCU 仅有电时允许有限 ToF 阈值/失效告警，统一固件输出调度。
- ToF 不是逐像素深度；晚到定位、校准、距离归属、遮挡降级和用户拿取确认不可省略。
- 依赖锁定及环境隔离，来源/代码许可/权重许可分别记录；不预先承诺 Android LocateAnything。
- 每轮记录失败和复测、指标实测/模拟标签、文档漂移、Git 哈希/远端核验、未完成与下一步。
- 交付 A 后必要时审计 B；B 不写自身哈希。下一轮补记 B。
- 工程原型不替代盲杖/陪同，不自动给出安全通行保证；照片/录音/凭据不入库。
