# Android 团队验收清单

每次记录手机完整型号/SoC/内存/Android 版本、commit、APK variant、固件、传感器、模型与参数。未测写“未测”，不得填 0。

1. 构建：JDK/SDK/Gradle 版本、依赖解析锁、unit/instrumentation、debug/release APK 哈希。
2. USB：用户拒绝/允许、非目标设备、双 bulk endpoint、XG03 黄金包、坏 CRC、短读写、500ms 部分包、握手/心跳、拔插/重启/换主机、30 分钟稳定性。
3. 生命周期：前后台、灭屏、进程回收、来电、音频焦点、USB-C 供电角色；未实现合规前台服务时后台不宣称持续监测。
4. 无障碍：TalkBack 顺序、五任务名称/状态、大触控、取消/重复、错误播报；绿灯不得形成过街许可。
5. 模型：逐模型固定来源/许可/文件 SHA、算子、量化前后任务指标、峰值内存、冷/热延迟、FPS、30 分钟温升/功耗/降频。LocateAnything 不可行时提交证据并请求用户选择，不默认换模型或上云。
6. 受控场景：保留盲杖、有人陪同；室内障碍/遮挡/反光/暗处/断传感器。禁止独立道路和过街测试。
7. 地图：高德控制台分别登记 debug/release SHA1 与 `com.trollhunter.xglasses`，Key 只在本机配置；记录固定 SDK/JAR 哈希、条款/配额/数据日期、目标地区和 WGS84→GCJ-02 偏移。测试首次拒绝、同意持久化、撤回授权、政策链接、定位权限、GPS 关闭、低精度/过期、无结果、断网、空/坏路线、到达、连续偏航重算。地图指令不得抢占传感失效/近障停止，也不得形成道路安全结论。
